使う Google のデータ

  • YouTube：動画のアップロードと予約（youtube.upload）、運営者のチャンネルの動画情報・再生数・視聴データの読み取り（youtube.readonly）
  • Google ドライブ：このツールが作ったか開いたファイルだけ（drive.file）。再生数を記録するスプレッドシートに使います。

使い道

運営者本人のチャンネルへの投稿と、その結果の記録だけに使います。

保存と共有

許可の情報と読み取ったデータは、運営者のコンピュータと運営者の Google スプレッドシートにだけ置きます。販売や広告には使いません。

許可の取り消し

Google アカウントのサードパーティ製のアプリとサービスから、いつでも取り消せます。

YouTube API サービス

このツールは YouTube API サービスを使います。YouTube 利用規約と Google プライバシーポリシーも適用されます。
